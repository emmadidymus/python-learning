## 🚀 Running the Code

Clone the repository:

```bash
git clone git@github.com:emmadidymus/python-learning.git
```

Navigate into the project:

```bash
cd python-learning
```

Run any example:

```bash
python3 path/to/file.py
```

Example:

```bash
python3 05_functions/basic_functions/hello.py
```
